Welcome to **Cafe Hub** — a modern, aesthetic cafe website built for Gen Z, creators, students, and coffee lovers!

## 🌟 How to View the Website

You can immediately open and view the website in any browser:

1. Navigate to the **`cafe-hub`** folder on your Desktop:
   ```
   c:\Users\DELL\OneDrive\Desktop\cafe-hub\index.html
   ```
2. **Double-click `index.html`** or right-click and choose **"Open with Chrome"** (or Edge/Brave/Firefox).
3. That's it! No build tools or installations needed — it works right out of the box with pure HTML, modern CSS, and vanilla JavaScript.
